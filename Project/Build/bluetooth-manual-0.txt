1. 软件说明 
1.1. 软件介绍 
塔克创新全新打造蓝牙手机遥控 APP，采用最新的 MD 设计语言，抽屉式框架。实现沉浸式
全屏操作，具有振动触感反馈，大摇杆，大按键，全屏幕设计，带来游戏级操控体验。可用于机器
人、智能车控制和调试，支持摇杆、按键、体感、坦克多种操作模式。 
 
注意，软件只支持塔克提供的蓝牙模块，非塔克蓝牙模块无法使用。 
1.2. 功能介绍 
软件集成了多种遥控器和常用机器人调试功能。遥控器包含摇杆模式、手柄模式、重力模式，
坦克模式、机臂模式等。 
 
常用机器人调试功能，包含灯光控制、数据调试、波形显示等功能。其中波形显示功能待开发
完善。可关注塔克微信公众号“塔克创新”，了解软件更新进展。

2. 基础使用说明 
软件只支持塔克提供的蓝牙模块，软件使用前需要先连接蓝牙模块进行授权，否则无法使用。 
2.1. 蓝牙模块 
配套蓝牙模块，既可以单独购买，也可以购买塔克机器人或智能车产品获得。蓝牙模块具有多
种形态，以下是部分样式效果。 
 
具体以实物为准，塔克配套蓝牙模块，购买链接如下。 
https://item.taobao.com/item.htm?spm=a2126o.success.0.0.5cc74831MVClyK&id=696631820028  
2.2. 蓝牙连接 
打开 APP 后，软件会自动进入蓝牙连接界面，扫描可用的塔克授权蓝牙设备。如果此时有塔
克蓝牙模块，会显示可用设备，并且显示蓝牙设备信号强度。点击连接，连接时会进行一次鉴权操
作，如果是授权设备，会连接成功。非授权设备会提示设备不可用。 
 
  注意，不进行蓝牙连接，无法进入软件操作界面。蓝牙连接成功后，左侧抽屉界面，会显示
蓝牙已连接，并且显示已连接的蓝牙设备。

过点选图标或左侧向右滑动弹出。 
 
弹出后，可选择不同功能，进入相应界面。软件设置和关于塔克用户可自行查看。

5.2. 接收参考代码 
使用塔克 OpenCTR 系列控制器，STM32 程序接收代码如下所示，仅供参考。 
//接收 
static u8 UART_RX_BUF[40];  // 接收缓冲，数据内容小于等于 32Byte 
static u8 UART_RX_CON = 0;  // 接收计数器 
static u8 UART_RX_CHECKSUM; //帧头部分校验和 
/** 
* @简  述  串口中断服务程序 
* @参  数  无 
* @返回值  无 
*/ 
void USART1_IRQHandler(void) 
{ 
 uint8_t Res; 
 
 if (USART_GetITStatus(USART1, USART_IT_RXNE) != RESET)  // 接收中断 
 { 
 
  Res = USART_ReceiveData(USART1); 
 
  if (UART_RX_CON < 3)    //== 接收帧头 + 长度 
  { 
   if (UART_RX_CON == 0)  // 接收帧头 1 0xAA 
   { 
    if (Res == 0xAA) 
    { 
     UART_RX_BUF[0] = Res;
