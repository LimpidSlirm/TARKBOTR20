1. 软件说明 
1.1. 软件介绍 
塔克创新全新打造蓝牙手机遥控 APP，采用最新的 MD 设计语言，抽屉式框架。实现沉浸式
全屏操作，具有振动触感反馈，大摇杆，大按键，全屏幕设计，带来游戏级操控体验。可用于机器
人、智能车控制。 
 
1.2. 功能介绍 
软件集成了多种遥控器和常用机器人调试功能。遥控器包含手柄模式、摇杆模式、重力模式、
坦克模式、机械臂控制等多种控制模式。

2. 基础使用说明 
软件只支持塔克提供的蓝牙模块，软件使用前需要先连接蓝牙模块进行授权，否则无法使用。 
2.1. 蓝牙模块 
APP 软件支持塔克 X-SBTCOM1 蓝牙串口模块，模块基于全新蓝牙 BLE 5.4 开发，主从一体
式设计，可通过按键快速切换工作模式、快速配对，无需复杂AT 指令，操作简单，如下图所示。 
 
蓝牙模块内置稳压电路，支持 3.3V 和 5V 供电，VCC 和 GND 引脚具有防反插保护设计。具
有蓝绿两个 LED 灯，用于主从模式和连接状态显示。关于蓝牙串口模块的详细使用，请参考配套
资料中《多功能蓝牙串口遥控模块用户手册》文档。

2.2. 蓝牙连接 
手机 APP 连接蓝牙模块，首先需要将蓝牙模块调节到从机模式，绿灯闪烁或常亮表示为从机
模式。长按按键 3S 可切换工作模式，具体操作可参考模块使用手册。 
 
打开 APP 后，软件会自动进入蓝牙连接界面，并扫描可用的塔克授权蓝牙设备。如果此时有
塔克蓝牙模块处于从机模式，且处于被搜索状态，绿灯闪烁，APP 会搜索到可用设备，显示可用设
备名称，并且显示蓝牙设备信号强度。 
点击设备名称即可连接，连接成功后，蓝牙模块绿灯常亮。 
 
  注意，只有连接蓝牙后才能进入主界面，不连接蓝牙无法进入软件操作界面。蓝牙连接成功
后，左侧抽屉界面，会显示蓝牙已连接，并且显示已连接的蓝牙设备。

4.1. 波形显示 
波形显示最多支持 8 个数据通道，支持帧率和帧 ID 显示，采用塔克标准 X-Protocol 协议。
点击右上角按钮，可弹出波形显示设置界面。 
 
可单独关闭每个通道，支持清空数据和停止接收功能。 
 
支持数据发送功能，可以边显示边发送。数据发送采用 X-Protocol 协议，可进行命令发送和
参数调试，帧编码范围为 0~255，数量为 1~8，每个数据为有符号 16 进制。适合机器人 PID 参
数调试。

4.2. 数据收发 
数据收发功能支持 ASCII 码和 16 进制显示，支持塔克 X-Protocol 协议解析功能，具有清空

void USART1_IRQHandler(void) 
{ 
 uint8_t Res; 
 
 if (USART_GetITStatus(USART1, USART_IT_RXNE) != RESET)  // 接收中断 
 { 
 
  Res = USART_ReceiveData(USART1); 
 
  if (UART_RX_CON < 3)    //== 接收帧头 + 长度 
  { 
   if (UART_RX_CON == 0)  // 接收帧头 1 0xAA 
   { 
    if (Res == 0xAA) 
    { 
     UART_RX_BUF[0] = Res; 
     UART_RX_CON = 1; 
    } 
    else 
    { 
 
    } 
   } 
   else if (UART_RX_CON == 1) //接收帧头 2 0x55 
   { 
    if (Res == 0x55) 
    { 
     UART_RX_BUF[1] = Res; 
     UART_RX_CON = 2;
