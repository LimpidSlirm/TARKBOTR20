# 精简工程使用说明

本目录顶层仅保留 Doc、Driver、FreeRTOS、Libraries、Project、Robot 六个文件夹。

- 唯一工程入口：`Project/xproject.uvprojx`。
- 构建：在本工程根目录运行 `Project\build.bat`，或 `pwsh -File Project/build-arm.ps1`。
- 固件：`Project/Build/competition.hex`，调试映像：同目录的 `competition.axf`。
- 下载：使用 Keil 或手动运行 `Project/flash.bat`；该脚本会先重新构建。
- 机械参数：`Robot/ax_chassis_config.h`；板型：`Robot/ax_board_config.h`。
- 详细改动：本目录的 `修改说明与使用方法.md`；验证记录：`验证结果.json`。

功能保持为此前的 H60 适配、P30/65mm/1024线磁编码器四轮差速和低速按键转向测试。
未新增导航、平滑加减速或角度闭环。源码和前一版已验证源码保持一致。

离线主机测试环境保留在上一级主工程，不增加本目录的顶层文件夹。本次不运行下载脚本、不连接小车。
